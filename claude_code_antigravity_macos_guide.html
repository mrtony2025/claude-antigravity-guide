Claude Code + Antigravity — macOS Setup

Hướng dẫn cài đặt từng bước, tối ưu cho máy của bạn

MacBook Pro M1 2020 macOS Tahoe 26.3.1 16 GB RAM Claude Code 2.1.81
1
Cài Antigravity IDE ▶

Cài Antigravity — IDE agent-first của Google, miễn phí hoàn toàn. Máy M1 dùng bản Apple Silicon.

Cách 1 — Homebrew (tự động cập nhật):

brew install --cask antigravity

Cách 2 — Tải thủ công (.dmg):

# Truy cập trình duyệt: antigravity.google/download # Chọn: Download for Apple Silicon (M1/M2/M3/M4)
Sau khi cài: mở Antigravity → đăng nhập Google Account → cấp quyền file system & network khi được hỏi.
2
Cài Claude Code CLI ▶

Cài Claude Code bằng native installer — không cần Node.js, tự động cập nhật trong nền.

curl -fsSL https://claude.ai/install.sh | bash

Sau khi cài, thêm vào PATH của zsh (lỗi bạn đã gặp trước đó):

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

Kiểm tra:

claude --version # Kết quả mong đợi: 2.1.81 (Claude Code) ✓
Bạn đã hoàn thành bước này rồi! Claude Code 2.1.81 đã cài thành công.
3
Lấy Anthropic API Key Auth ▶

Claude Code cần tài khoản Anthropic. Chọn một trong hai cách:

Claude Pro/Max

Subscription $20/tháng. Đăng nhập bằng account claude.ai hiện có.

API Key (Pay-as-you-go)

Nạp $5 credit. Phù hợp nếu dùng không thường xuyên.

Lấy API Key: console.anthropic.com → API Keys → Create Key → Copy ngay (chỉ hiện 1 lần).

Cộng đồng khuyên dùng bản Max ($100/tháng) hoặc API Key nếu code nhiều — bản Pro $20 dễ hết limit.
4
Cài Claude Code Extension trong Antigravity Extension ▶

Antigravity là VS Code fork, hỗ trợ cài extension như bình thường:

# Trong Antigravity: Cmd + Shift + X → mở Extensions Tìm: "Claude Code" → cài extension của Anthropic

Sau khi cài, click icon Spark (⚡) trong sidebar trái → mở panel Claude Code.

# Đăng nhập Claude Code trong Antigravity: /log → gõ lệnh này trong chat panel → chọn API key hoặc Claude account
Bạn đã thấy panel /log đang "Generating..." trong screenshot trước — đúng hướng rồi!
5
Khởi động dự án đầu tiên Workflow ▶

Mở dự án trong Antigravity, sau đó khởi tạo Claude Code:

# Trong terminal của Antigravity: cd ~/your-project claude # Lần đầu sẽ mở trình duyệt để xác thực

Trong Claude Code panel, chạy /init để Claude đọc codebase:

/init → tạo file CLAUDE.md với context dự án

Workflow kết hợp tối ưu:

Antigravity Gemini 3 — lên kế hoạch, thiết kế architecture, brainstorm
↓
Claude Code Implement code, sửa bug, quản lý git
↓
Review Xem diff/artifacts trong Antigravity, iterate
6
Các lệnh hay dùng nhất Tips ▶

Các slash command quan trọng trong Claude Code:

/init → đọc codebase, tạo CLAUDE.md /compact → tóm tắt context (dùng sau 30+ turns) /clear → xóa conversation history /model → chuyển model (Sonnet/Opus) /mcp → quản lý MCP servers /bug → báo lỗi trực tiếp cho Anthropic /help → xem tất cả lệnh

Tips M1 MacBook:

# Cập nhật Claude Code: curl -fsSL https://claude.ai/install.sh | bash # Nếu terminal trong Antigravity không nhận claude: source ~/.zshrc # Kiểm tra PATH: which claude # → /Users/[user]/.local/bin/claude

Hoàn thành setup!
