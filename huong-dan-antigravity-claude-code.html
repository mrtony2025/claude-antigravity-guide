01 Cài Antigravity

Antigravity hoàn toàn miễn phí trong public preview. Tải tại antigravity.google/download

Cách 1 — Homebrew (khuyến nghị)

# Cài qua Homebrew:
brew install --cask antigravity

# Cập nhật khi cần:
brew upgrade antigravity

Cách 2 — Tải .dmg thủ công

1
Truy cập antigravity.google/download
Chọn "Download for Apple Silicon" (M1/M2/M3/M4) — file ~180MB
2
Mở file .dmg → kéo vào Applications
macOS có thể hiện cảnh báo bảo mật → System Settings → Privacy & Security → Allow
3
Launch → đăng nhập Google Account
Cấp quyền file system + network khi được hỏi. Setup mất ~2-3 phút lần đầu.

02 Cài Claude Code

Cài native installer (không cần Node.js)

# Cài Claude Code — tự động cập nhật:
curl -fsSL https://claude.ai/install.sh | bash

# Fix PATH cho zsh (quan trọng):
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

# Kiểm tra thành công:
claude --version
# → 2.1.81 (Claude Code) ✓
Lần đầu chạy claude trong folder dự án, trình duyệt tự mở để xác thực. Cần Claude Pro ($20/tháng) hoặc API key từ console.anthropic.com.

Cài extension Claude Code trong Antigravity

# Trong Antigravity:
Cmd + Shift + X          → mở Extensions
Tìm: "Claude Code"       → cài extension của Anthropic
Click icon Spark (⚡)    → mở panel Claude Code

# Đăng nhập trong panel:
/log                     → chọn API key hoặc Claude account

03 Cài Gemini CLI

Free tier: 60 requests/phút · 1,000 requests/ngày · Gemini 2.5 Pro · 1M token context · Không cần credit card

Yêu cầu: Node.js 20+

# Kiểm tra version Node:
node --version
# Nếu dưới 20, cài lại:
brew install node

Fix lỗi EACCES trước khi cài (quan trọng)

Không dùng sudo — sẽ sinh ra nhiều lỗi permission về sau. Fix đúng cách bằng npm-global:
# Fix permission + cài Gemini CLI — chạy toàn bộ 1 lần:
mkdir -p ~/.npm-global && \
npm config set prefix '~/.npm-global' && \
echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc && \
source ~/.zshrc && \
npm install -g @google/gemini-cli && \
gemini --version
# → 0.34.0  ✓ thành công

Đăng nhập lần đầu

1
Mở Gemini CLI trong folder dự án
cd ~/your-project && gemini
2
Chọn theme → chọn "Login with Google"
Trình duyệt mở ra → đăng nhập Google Account cá nhân (không dùng Workspace)
3
Khởi tạo project
Gõ /init → Gemini CLI tạo GEMINI.md, đọc codebase

04 File ~/.zshrc hoàn chỉnh

Toàn bộ config cần thiết — paste vào cuối file ~/.zshrc:

# ════════════════════════════════════════
# AI Coding Tools — Claude Code + Gemini
# Thêm vào cuối ~/.zshrc
# ════════════════════════════════════════

# PATH
export PATH="$HOME/.local/bin:$PATH"          # Claude Code
export PATH="$HOME/.npm-global/bin:$PATH"      # Gemini CLI + npm global

# API Keys (thay bằng key thật)
export KIMI_API_KEY="sk-your-kimi-key"
export OR_API_KEY="sk-or-v1-your-openrouter-key"

# ── Claude Code aliases ──────────────────
alias cc='claude'                                 # Sonnet 4.6 mặc định
alias cco='claude --model claude-opus-4-6'         # Opus — task khó
alias cch='claude --model claude-haiku-4-5-20251001' # Haiku — nhanh/rẻ
alias cck='ANTHROPIC_BASE_URL="https://api.moonshot.cn/v1" ANTHROPIC_API_KEY="$KIMI_API_KEY" claude --model kimi-k2-0711-preview'
alias ccor='ANTHROPIC_BASE_URL="https://openrouter.ai/api/v1" ANTHROPIC_API_KEY="$OR_API_KEY" claude --model deepseek/deepseek-r2'
alias ccg='ANTHROPIC_BASE_URL="https://openrouter.ai/api/v1" ANTHROPIC_API_KEY="$OR_API_KEY" claude --model google/gemini-2.5-pro'

# ── Gemini CLI alias ─────────────────────
alias gm='gemini'                                 # Gemini CLI free

# ════════════════════════════════════════
# Áp dụng ngay:
source ~/.zshrc

# Test tất cả alias:
cc --version    # → 2.1.81 (Claude Code)
gm --version    # → 0.34.0

05 Cài MCP servers

MCP (Model Context Protocol) cho phép Claude Code và Gemini CLI gọi tool bên ngoài — GitHub, Supabase, Slack...

Config file: ~/.claude/settings.json

{
  "model": "claude-sonnet-4-6",
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "your_token" }
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "~/projects"]
    }
  }
}
# Quản lý MCP trong Claude Code:
/mcp            → xem MCP đang kết nối
/mcp add        → thêm MCP server mới
/mcp status     → kiểm tra kết nối

07 Workflow kết hợp tối ưu

1
Antigravity (Gemini 3.1) — lên kế hoạch
Chat box bên phải Antigravity. Mô tả tính năng → Gemini trả về plan + file structure. Tiết kiệm Claude token cho bước planning.
2
Claude Code (Sonnet 4.6) — implement
Copy plan từ Antigravity → paste vào Claude Code terminal. Claude Code viết code, tạo file, chạy lệnh. Approve từng action.
3
Git commit sau mỗi feature
git add . && git commit -m "feat: ..." — lưới an toàn quan trọng nhất.
4
Khi hết Claude quota → chuyển sang gm
Gemini CLI có 1,000 req/ngày free. Dùng @web để search docs realtime trong lúc code.

09 Tiết kiệm token

Tips tiết kiệm token hiệu quả nhất:
· Dùng Gemini (Antigravity) để planning — không tốn Claude token
· Viết CLAUDE.md chi tiết — Claude đọc 1 lần thay vì giải thích lại mỗi session
· Chỉ hỏi về file liên quan, không paste toàn bộ codebase
· /compact sau 20-30 lượt, /clear khi chuyển task hoàn toàn mới
